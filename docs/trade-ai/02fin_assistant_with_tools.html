Financial assistant with MCP stock tools, sync REPL over an async client.
 
Adds the MCP tools from stock_mcp_server.py (list_market_prices, list_trades,
create_trade, etc.) via MultiServerMCPClient over HTTP, so the agent can look
up real data instead of just answering from its own knowledge.
 
MultiServerMCPClient.get_tools() and agent.ainvoke() are async-only, but the
REPL loop here stays synchronous (input()/print()) like 01fin_assistant.py -
each turn wraps the async call with asyncio.run(), which creates and tears
down a new event loop per call. Simple, but has that per-turn overhead.
 
See 03fin_assistant_async.py for the version that runs the whole REPL inside
one event loop instead (no per-turn asyncio.run()).
 
Requires stock_mcp_server.py running on http://127.0.0.1:8001 and the
trade-backend API running on http://127.0.0.1:8000.
